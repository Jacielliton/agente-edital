🚀 Agente Edital - Deploy e Manutenção

Este guia contém os procedimentos para garantir que a VPS fique segura, estável e fácil de manter. Siga este checklist para evitar invasões, quedas de serviço e automatizar suas atualizações.

🛡️ 1. Segurança Básica e Firewall

O Nginx (Porta 80/443) faz a comunicação com o Python internamente. Ninguém de fora deve acessar a porta 8001 diretamente.

# 1. Garanta que o SSH (seu acesso) esteja liberado (ESSENCIAL)
sudo ufw allow ssh

# 2. Libere o Nginx (Site HTTP e HTTPS)
sudo ufw allow 'Nginx Full'

# 3. BLOQUEIE a porta 8001 (O Python só conversa com o Nginx localmente)
sudo ufw delete allow 8001/tcp

# 4. Ative o Firewall
sudo ufw enable
Nota: Se perguntar "Command may disrupt existing ssh connections", digite y e Enter.

🔒 2. Certificado SSL Automático (HTTPS)

Garante que o site não saia do ar por expiração de certificado.

# 1. Instale o Certbot
sudo apt install certbot python3-certbot-nginx

# 2. Gere o certificado (configura o Nginx sozinho)
sudo certbot --nginx -d agente-edital.tecnopriv.top

# 3. Verifique a renovação automática
sudo systemctl status snap.certbot.renew.service
# OU
sudo systemctl list-timers | grep certbot

⚙️ 3. Inicialização Automática (Auto-Start)

Se a VPS reiniciar, os serviços precisam voltar sozinhos.

  • Docker (Banco de Dados): Verifique se no docker-compose.yml há a instrução restart: always no serviço do DB.
  • Backend (Python): Ative o Systemd rodando sudo systemctl enable agente-edital.
  • Frontend (Nginx): Já inicia no boot por padrão no Ubuntu.

🔄 4. Como Atualizar o Site (Deploy)

Utilize o fluxo automatizado para atualizar o site sem quebrar URLs ou perder arquivos.

Fase 1: No seu Computador (Local)

git add .
git commit -m "Descreva sua alteração"
git push origin main

Fase 2: Na VPS (Automático)

Criamos um script que baixa, configura URLs de produção e reinicia tudo com um comando. Certifique-se de ter o arquivo deploy.sh na raiz do projeto (/opt/agente-edital).

#!/bin/bash

echo "🔄 Baixando atualizações do Git..."
git pull origin main

echo "📦 Atualizando o Backend..."
cd backend
source venv/bin/activate
# pip install -r requirements.txt 

echo "🎨 Atualizando o Frontend..."
cd ../frontend
npm install

echo "🔗 Ajustando URLs da API para Produção..."
grep -rl "localhost:8000" src | xargs -r sed -i 's|http://localhost:8000|https://agente-edital.tecnopriv.top/api|g'
grep -rl "localhost:8001" src | xargs -r sed -i 's|http://localhost:8001|https://agente-edital.tecnopriv.top/api|g'

echo "🏗️ Construindo arquivos estáticos do React..."
npm run build

echo "🚀 Reiniciando o serviço do Backend..."
sudo systemctl restart agente-edital

echo "✅ Sistema atualizado com sucesso!"

Para rodar o deploy:

cd /opt/agente-edital
./deploy.sh
Dica de Ouro: Se as mudanças não aparecerem imediatamente no navegador após o deploy, pressione Ctrl + F5 para limpar o cache.

🆘 5. Solução de Problemas (Troubleshooting)

Erro de Conflito no Git (Merge Overwritten)

Se o script de deploy falhar com o erro "Your local changes would be overwritten by merge", force a VPS a espelhar o GitHub:

cd /opt/agente-edital
git fetch --all
git reset --hard origin/main
./deploy.sh

Deploy Manual (Passo a Passo)

Se preferir ou precisar debugar, a ordem manual é:

# 1. Puxar código
git pull origin main

# 2. Frontend
cd frontend
npm install
grep -rl "localhost:8000" src | xargs -r sed -i 's|http://localhost:8000|https://agente-edital.tecnopriv.top/api|g'
npm run build

# 3. Backend
cd ../backend
sudo systemctl restart agente-edital
sudo systemctl status agente-edital
